使用變數

宣告變數的語法：資料型態 變數名稱;
int x;
double y;
boolean z;
char c;
String s;

宣告變數、同時指定資料：資料型態 變數名稱 = 資料;
int x = 3;

先宣告變數、然後指定資料
資料型態 變數名稱
變數名稱 = 資料;
double y;
y = 3.5;

＊＊資料必須和宣告的資料型態一樣，否則報錯

使用變數

在終端機印出資料的指令：
System.out.printin(任意資料);

沒有使用變數：
System.out.printin(3);
System.out.printin(true);

使用變數：
int x = 3;
System.out.printin(x);    
程式會去尋找x裡放的資料。印出3
